Bean Boutique is a responsive website designed to showcase a premium coffee brand. It features sections for coffee machines, coffee beans, promotions, and contact information.
The project focuses on clean UI, modern styling, and smooth user experience.

🛠️ Features

- Fully responsive layout

- Homepage with hero section

- Product showcase (Coffee Machines & Beans)

- Navigation bar & footer

- Modern clean design using HTML, CSS, and JavaScript
  

🔧 How to Run the Project

- Clone the repository:

- git clone https://github.com/nadi4567/Bean-Boutique.git


- Open index.html in your browser.

- See demo at https://nadi4567.github.io/Bean-Boutique/
